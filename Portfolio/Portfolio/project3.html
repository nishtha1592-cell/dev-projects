Terra Eco-Store

A premium, niche E-commerce experience focused on sustainable furniture. This project demonstrates a deep understanding of the "Customer Journey," from product discovery to a multi-step simulated checkout process.

Key Features

  • Advanced Filtering:

    A sidebar that allows multi-criteria filtering (e.g., Filter by Material: 'Wood' + Price: '$200').

  • Interactive Shopping Cart:

    A slide-out "Mini-Cart" with real-time quantity updates and subtotal calculations

  • Product Detail Pages:

    Dynamic routing where each product has its own custom URL and high-resolution image gallery.

  • Simulated Checkout:

    A polished 3-step form (Shipping -> Payment -> Confirmation) with form validation.

Tech Stack

  • Framework:

    Next.js (App Router)

  • Database (Mock)

    Supabase or a local JSON-server

  • Form Handling:

    React Hook Form + Zod (for validation)

  • Styling:

    CSS Modules or Tailwind
