Ink & Paper

A developer-centric Markdown blogging engine. It is designed to be a "Static Site" that converts local text files into a beautiful, SEO-optimized reading experience, proving you understand how the web handles content.

Key Features

  • Markdown-to-HTML:

    Automatically parses .md files with support for code syntax highlighting (Prism.js).

  • Estimated Reading Time:

    A logic function that calculates reading time based on a 200 words-per-minute average.

  • Tagging System:

    An automated index that groups posts by tags (e.g., "JavaScript," "Career," "Tutorials").

  • SEO Meta-Generator:

    Automatically generates OpenGraph tags for social media sharing for every post.

  • Static Site Generator:

    Astro or Next.js (Static Export)

  • Content:

    Gray-matter (for metadata) + Remark (for parsing)

  • Styling:

    Typography.js or Tailwind Typography plugin
