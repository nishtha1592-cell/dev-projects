Nexus Dashboard

A high-performance Business Intelligence (BI) dashboard designed for SaaS founders to track real-time growth metrics. This project focuses on data visualization and complex state management, transforming raw JSON data into actionable business insights with a clean, "Apple-style" minimalist interface.

Key Features

  • Dynamic Data Visuals:

    Interactive Line, Area, and Pie charts showing MRR (Monthly Recurring Revenue) and Churn using Recharts.

  • Metric Toggles:

    Users can switch views between "Daily," "Weekly," and "Monthly" data perspectives.

  • User Management Table:

    A searchable, sortable list of "customers" with status badges (Active, Pending, Canceled).

  • Dark Mode Support:

    A fully responsive theme-switching engine using Tailwind CSS.

Tech Stack

  • Frontend:

    React.js / Next.js

  • Styling:

    Tailwind CSS + Shadcn UI

  • Charts:

    Recharts or Chart.js

  • State Management:

    TanStack Query (React Query)
