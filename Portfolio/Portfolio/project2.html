Velo Finance

A "Paper Trading" platform that allows users to simulate cryptocurrency investments without real financial risk. The app fetches real-time market data from public APIs and provides a secure-feeling environment to manage a virtual $10,000 portfolio.

Key Features

  • Real-Time Price Engine:

    Fetches live prices for BTC, ETH, and SOL using the CoinGecko API.

  • Transaction Simulator:

    Logic-based "Buy/Sell" system that updates a virtual balance and calculates profit/loss percentages.

  • Watchlist:

    A custom "Favorites" feature where users can save coins to track them closely.

  • Persistence:

    Uses Browser LocalStorage to ensure the user's virtual balance and history remain even after a page refresh.

Tech Stack

  • Frontend:

    React (TypeScript)

  • Icons/UI:

    Lucide React + Framer Motion (for smooth animations)

  • API:

    CoinGecko Public API

  • State:

    Redux Toolkit or Zustand
